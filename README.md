## 🚀 How to Make It Live on GitHub (Free)

### Step 1: Create a GitHub Repository
1. Go to [GitHub New Repository](https://github.com/new).
2. Set the repository name to:
   ```text
   muhammad-adeel9290.github.io
   ```
   *(Make it **Public** and leave 'Add README' unchecked).*

### Step 2: Push Your Portfolio
Open PowerShell or Git Bash in this folder (`C:\Users\Adeel\.gemini\antigravity\scratch\muhammad-adeel-portfolio`) and run:

```bash
git init
git add index.html
git commit -m "Launch Muhammad Adeel DevOps Portfolio"
git branch -M main
git remote add origin https://github.com/muhammad-adeel9290/muhammad-adeel9290.github.io.git
git push -u origin main
```
